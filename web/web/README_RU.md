# GiftGram — Telegram Mini App

Адаптивная Mini App с тёмным неоновым интерфейсом, рассчитанная на запуск и настройку с телефона.

## Уже реализовано
- Telegram-бот с `/start` и кнопкой открытия Mini App
- Проверка подлинности Telegram `initData` на сервере
- Баланс игровых звёзд и ежедневная награда +100 (один раз в день по UTC)
- Кейс за 50 игровых звёзд с пятью редкостями
- Коллекция NFT и прокачка за игровые звёзды
- Хранение пользователей и предметов в SQLite
- API для баланса, наград, кейсов и улучшений

## Важно
Игровые звёзды и предметы — демонстрационная игровая экономика. Это не реальные Telegram Stars, не блокчейн-NFT и не обещание денежной ценности. Не включай `DEV_MODE=true` на публичном хостинге.

## Подготовка через телефон
1. В Telegram открой `@BotFather` и отправь `/newbot`.
2. Скопируй токен бота и сохрани его в секрете.
3. Создай GitHub-репозиторий через браузер телефона.
4. Загрузи содержимое архива в репозиторий (распакуй ZIP перед загрузкой).
5. Создай Python web service на хостинге, который поддерживает постоянно работающий процесс и переменные окружения.
6. Build/install command: `pip install -r requirements.txt`
7. Start command: `python main.py`
8. Добавь переменные окружения:
   - `BOT_TOKEN` = токен из BotFather
   - `WEBAPP_URL` = публичный HTTPS URL этого сервиса, например адрес, выданный хостингом
   - `PORT` = обычно хостинг задаёт автоматически; если нет, можно `8000`
9. Опубликуй сервис. Если хостинг требует адрес заранее, сначала разверни web-сервис, затем внеси его HTTPS URL в `WEBAPP_URL` и перезапусти сервис.
10. Открой бота и отправь `/start`.

## Ограничения бесплатного хостинга
Бесплатные планы могут засыпать, ограничивать часы работы или не сохранять локальный SQLite-файл при перезапуске. Для стабильной работы нужен постоянный worker и persistent disk/managed database. Проверяй условия выбранного хостинга.

## Безопасность и следующие улучшения
- Никогда не вставляй токен в исходный код или публичный репозиторий.
- Если токен утёк — отзови его в `@BotFather`.
- Для production лучше перейти с SQLite на PostgreSQL и добавить резервные копии, лимиты запросов, логи и административную панель.
- Настоящие цифровые товары, платёжные функции и вывод средств требуют отдельной реализации и проверки правил Telegram.
